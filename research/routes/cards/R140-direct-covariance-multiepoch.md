# Coordinator precommit: minimal RPCD specification

This file was written by the research coordinator, not generated by an
independent Agent rollout. Its hash records the staged first-phase specification;
it must never be counted as realized sealed search breadth or represented as an
Agent-authored route card.

For every real unit-diagonal SPD matrix `A`, let
`mu=lambda_min(A)`. Each RPCD epoch draws a fresh independent uniform
permutation. Seek universal numerical constants `c,C>0` and a mathematical
argument implying

```text
E ||x_k||_A <= C exp(-c mu k) ||x_0||_A
```

for every initial point and every epoch count `k`. The required complexity is
therefore `O((n/mu) log(1/epsilon))` coordinate updates. The conclusion must be
the expectation of distance, not the distance of the expected iterate.

Before revealing any prior work, independently choose a mathematical method and
write `route_card.json` containing:

1. the mathematical representation;
2. the state or invariant retained by that representation;
3. one falsifiable core lemma and its exact target transfer;
4. the information deliberately retained and discarded;
5. at least two analytic falsifiers, including one noncommuting example;
6. the predicted first failure edge and the branch to take if it fails.

No representation or proof family is prescribed by this specification. The
fanout manifest assigns different method families to independent rollouts.
Numerical null searches may select or prune a route but cannot certify a general
statement.
