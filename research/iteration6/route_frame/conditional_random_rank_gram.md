# Conditional random-rank Gram identity

Status: exact averaged triangular-projection lemma (E3 proof candidate) for a
frozen cross-row matrix, followed by the precise adaptation gap for RPCD
local inverses.  It is not yet the desired covariance theorem.

## 1. Exact two-sided rank averaging

Let `C` be any fixed real `m x m` matrix.  Independently permute its row and
column labels, and let `G` keep entries on/below the random rank diagonal
while `H` keeps entries strictly above it.  Embed both matrices back in the
original row/column labels, so `C=G+H` entrywise for every pair of ranks.
Then, with `Z=CC^T`, exact sampling without replacement gives

```
E[GG^T]
 = (m+1)/(3m) Z +(m+1)/(6m) Diag(diag Z),                (G1)

E[HH^T]
 = (m-2)/(3m) Z +(m+1)/(6m) Diag(diag Z).                (G2)
```

In particular,

```
E[GG^T] = E[HH^T] +(1/m)CC^T.                            (G3)
```

Proof: conditional on two row ranks `r,s`, a column contributes to their
common lower part with probability `min(r,s)/m`.  A single uniform rank has
mean `(m+1)/2`; the minimum of two distinct uniform ranks has mean
`(m+1)/3`.  For the strict upper part use `m-r` on the diagonal and
`m-max(r,s)` off diagonal; the corresponding means are `(m-1)/2` and
`(m-2)/3`.  Substitution proves (G1)--(G3), including the diagonal terms.

This identity explains why random internal ranks can cure the logarithmic
norm of deterministic triangular projection: the dangerous lower triangle
is exactly balanced by the complementary upper triangle, with only a
`1/m` full-Gram correction.  It is stronger and more relevant than merely
pairing a permutation with its reversal, which leaves internal ranks fixed
and is refuted in `reverse_pair_triangular_barrier.md`.

The cancellation is actually operator-valued.  For every fixed symmetric
column weight `W` (in particular `W=A_E^-1`),

```
E[G W G^T]=E[H W H^T]+(1/m)C W C^T.                     (G3w)
```

For completeness, fix two row labels and two column labels.  According as
the labels in each pair agree or differ, the lower-mask probabilities are

```
(m+1)/(2m), (m+1)/(3m), (m+1)/(3m),
(m+1)(3m-2)/[12m(m-1)],
```

while the corresponding strict-upper probabilities are

```
(m-1)/(2m), (m-2)/(3m), (m-2)/(3m),
(m-2)(3m-5)/[12m(m-1)].
```

Every lower-minus-upper difference is exactly `1/m`, proving (G3w)
entrywise.  If `C` is a cross-Gram matrix `C=W_rows V_E^T`, matrix Bessel
then gives

```
(1/m)C A_E^-1C^T <=(1/m)W_rows W_rows^T.                 (G3b)
```

Thus the correction left after true internal-rank averaging is harmless;
the unresolved object is the complementary adapted upper term.

## 2. Where the frozen-row proof stops for the half-window inverse

For `n=2a`, `q=a`, write `m=a-1`.  Conditional on the unordered early,
middle, and late label sets, a late row at internal rank `r` forgets exactly
the first `r` early ranks.  Its residual entries have the Gram form

```
F_(r,j)=<w_r,v_(beta_j)>   for j<=r,                      (G4)
```

where `w_r` is the feature vector represented by the local inverse row.
The important measurability fact is exact: `w_r` depends on the ordered
early suffix `beta_(r+1:m)`, the middle labels, and the late prefix, but not
on the order within the forgotten early prefix.

However, the matrix of unmasked correlations in (G4) is **not frozen while
the boundary rank moves**: changing `r` changes both the current late label
and the local solve window, hence changes `w_r`.  Nor is the complementary
upper matrix in (G3) literally the retained coefficient block of `D`.
For a retained coordinate `j`, triangular local inversion gives

```
d_j + sum_(i>j) d_i A_ij=0,
```

whereas its full Gram correlation is

```
<w,v_j>=sum_(i<j)d_i A_ij.                               (G5)
```

Thus (G3) cannot be substituted directly into `Q` or `P`.

## 3. Reverse-filtration formulation of the missing estimate

Condition on the late order.  Reveal the early permutation backwards and
let `F_j` be the sigma-field generated by the suffix after rank `j`.  For a
fixed test vector, put `y=Dx` and

```
g_j=sum_(r>=j) y_r w_r.
```

Then `g_j` is `F_j`-measurable and the forgotten label at rank `j` is uniform
among the `j` remaining labels.  Therefore the tail part has the exact
conditional second-moment representation

```
E[||F^T y||^2]
 =sum_j E[(1/j) sum_(i remaining at j) <g_j,v_i>^2].      (G6)
```

Equation (G6) is a genuine random-prefix/martingale reduction.  A scalar
row sum replaces the right side by `sum_j ||g_j||^2` and loses a harmonic
or worse factor; that is precisely the already-closed route.  The needed
new lemma is an operator Hardy/Bessel inequality for these *adapted local
solve vectors* which compares (G6), together with its cross term in
`||(I+F)^TDx||^2`, to the averaged frame `PAP`.  The frozen identity (G3)
shows the desired constant is plausible only if this adaptation is used,
and (G5) identifies the term a proof must pay for.

`scripts/verify_random_rank_gram.py` checks (G1)--(G3w) by exact enumeration.
