# Conditional dual-regression hierarchy

Status: exact general proof candidate (E3) and a concrete bridge from the
dual frame to cyclic-cut averaging.  It does not yet provide a uniform
constant.

## 1. Conditional certificates

For each random order let

```
X=M^-1,
R=D^TD,
Y_0=M^T R.
```

Let `G` be any sigma-field generated by partial information about the random
order, and define conditional moments

```
P_G=E[R|G],
Q_G=E[RMM^TR|G]=E[Y_0^TY_0|G].                           (H1)
```

Allow the deterministic regression coefficient to depend on `G`.  Expanding
the conditional square

```
E[(X-Y_0W_G)^T(X-Y_0W_G)]>=0
```

and using the pathwise identity `X^TY_0=R` gives, after optimizing
`W_G=Q_G^-1P_G`,

```
K=E[X^TX] >= C_G:=E[P_G Q_G^-1P_G].                      (H2)
```

This strictly generalizes the global feature certificate: for the trivial
sigma-field it is `P Q^-1P`.

## 2. A monotone martingale hierarchy

If `G` is coarser than `H`, then

```
C_G<=C_H<=K.                                             (H3)
```

Indeed, the matrix fractional map

```
(P,Q) ->P Q^-1P
```

is jointly matrix convex (its epigraph is the Schur-complement LMI
`[[Q,P],[P,T]]>=0`).  Conditional Jensen and the tower property give the
first inequality in (H3).  At the finest sigma-field revealing the entire
order,

```
R(RMM^TR)^-1R=M^-T M^-1=X^TX,                            (H4)
```

so the hierarchy terminates exactly at `K`.

There is an exact quantitative refinement, stronger than invoking joint
convexity alone.  Put

```
W_G=Q_G^-1P_G,   W_H=Q_H^-1P_H.
```

Then

```
C_H-C_G
 =E[(W_H-W_G)^T Q_H(W_H-W_G)].                           (H3b)
```

Indeed `Q_HW_H=P_H`; both cross terms reduce by conditioning to
`E[P_GQ_G^-1P_G]`, and the final `W_G^TQ_HW_G` term does the same because
`E[Q_H|G]=Q_G`.  Thus every information refinement adds an explicit PSD
Pythagorean square.  Along a filtration revealing a cycle, then a cut (or
successive ranks), the total gap to the exact moment telescopes into these
squares.  A future proof can lower-bound selected increments rather than
trying to compare the endpoints in one step.

This is a genuine matrix-valued martingale/Bellman interpolation: increasing
the order information can only strengthen the certified lower bound, and no
unproved scalar Jensen reversal is used.

## 3. The cyclic-cut level

Take `G` to reveal the directed cyclic order but not its uniformly random
cut.  Then (H2) becomes

```
C_cycle=E_cycle[P_cycle Q_cycle^-1P_cycle],               (H5)
```

where both conditional moments average only `n` cuts.  By
`cyclic_cut_freezing.md`, the defect rows in those `n` outcomes are fixed
cyclic local solves multiplied by explicit arc-incidence masks.  Thus (H5)
removes all covariance between unrelated cycles before applying the inverse;
it is strictly at least as strong as the global `P Q^-1P` certificate and
is tailored to the exact interval-overlap kernel.

There are two remaining obstacles:

1. `D_cut` still changes in the congruence surrounding the frozen defect.
2. A fixed adversarial cycle can have a large interval-truncation norm, so a
   final bound may still need the outer average over cycles in (H5).

Nevertheless (H2)--(H5) show that a proof is not forced to establish the
strong global covariance inequality posed at the start of the route.  It
may certify the same RPCD moment through a more informative conditional
frame, while remaining portable and exactly checkable.

`scripts/verify_conditional_dual_hierarchy.py` reconstructs the trivial,
cyclic-cut, and full-order levels by exact enumeration and checks both their
Loewner ordering and the Pythagorean identity (H3b) on finite rational
examples.
