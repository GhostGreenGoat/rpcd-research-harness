# T090 constant assessment after the T080 counterexample

Status: mixed exact proof drafts and explicitly labelled numerical attacks.  The original
covariance-map conjecture C001 is not addressed here.

## 1. What remains of the boundary matrix route

The exact `n=8` examples disprove the boundary constant two, but they do not disprove existence of
a universal positive constant in

`K_0(C) >= c P_{ker C}`.                                      (1)

The two-pole/simplex family already in
`docs/ITER4_T080_REVERSE_PAIR_SUBROUTE.md` proves that no `c>3/2` can hold.  For two duplicate
poles and a `k`-point simplex ring at latitude `a`, the pole-odd reducing coefficient satisfies

`lim_{k->infinity} lambda_{k,a}=1+1/(2-a^2)`,

and the right side decreases to `3/2` as positive `a` decreases to zero.  Thus `3/2`, if true, is
sharp.

The new moment-DP attack in `scripts/iter4_t090_constant_attack.py` also retains the second,
pole-even kernel direction and its coupling to the trivial range direction.  At the simple exact
point `k=6,a=2/3`, it agrees entrywise at the needed bilinear forms with the independent full
`2^8` subset DP:

```
odd Schur coefficient = 1057837/531441,
even Schur coefficient = 616286806298099/272688930830412.
```

A float64 scan over `k<=2000` and twelve latitudes found no coefficient below `3/2`; its smallest
value was about `1.52311`.  This is only a null search.  The exact universal boundary statement

`K_0(C) >= (3/2)P_{ker C}`                                  (2)

remains open, and any proof must be asymptotically lossless on the pole/simplex family.

## 2. The tempting global constant one is false

For an SPD correlation matrix define

`gamma(A)=lambda_min(A^(1/2) K(A) A^(1/2))`.

The global statement `gamma(A)>=mu`, where `mu=lambda_min(A)`, would give the desired complexity,
but it is false even on a signed-rank-one lift.  By diagonal sign conjugation it suffices to take

`A=mu I+(1-mu)11^T`.

On the parallel vector `1`, the forward triangular solve is independent of the permutation and is

`M_pi^{-1}1=(1,mu,mu^2,...,mu^(n-1))`

in permutation order.  Hence

```
kappa_parallel=(1-mu^(2n))/[n(1-mu^2)],
lambda_parallel(A)=n-(n-1)mu,
gamma(A) <= [n-(n-1)mu](1-mu^(2n))/[n(1-mu^2)].            (3)
```

For the exact rational instance `n=9, mu=9/10`, the right side is the actual minimum and equals

```
44731861300157941/50000000000000000
=0.89463722600315882... < 0.9=mu.                          (4)
```

The exact gap is `-268138699842059/50000000000000000`.  Formula (4) is independently generated by
the type-word second-moment DP, but its closed form in (3) is already a direct hand proof.

More importantly, divide (3) by `mu`, first send `n` to infinity with fixed `mu<1`, and then send
`mu` upward to one:

```
lim_{mu->1} lim_{n->infinity} gamma(A)/mu
 <= lim_{mu->1} 1/[mu(1+mu)] = 1/2.                       (5)
```

Therefore **no global one-step energy certificate with any universal `c>1/2` is possible**.  The
identity matrix only shows equality for `c=1` at one point; it is not globally sharp.  The bad
direction in (3) is the high-eigenvalue parallel direction, whereas the boundary `3/2` obstruction
comes from a null direction.  The two constants therefore measure different regimes.

The same family also proves that `1/2` is attained from above rather than crossed.  Put
`S_n=sum_{j=0}^{n-1}mu^(2j)` and `z=mu^(2n)`.  The parallel ratio decomposes as

```
g_parallel/mu
 = S_n/n + (1-z)/[mu(1+mu)].                               (5a)
```

Since `S_n/n>=mu^(2n-2)=z/mu^2`,

```
g_parallel/mu
 >= 1/[mu(1+mu)] + z/[mu^2(1+mu)] > 1/2.                  (5b)
```

On a transverse right side `e_i-e_j`, the first distinguished coordinate contributes solve
energy one.  Before the second is encountered, the accumulated solve sum keeps the same sign, so
the second distinguished solve value has magnitude at least one.  Thus every order has total
solve energy at least two, and the normalized transverse `K` eigenvalue is at least one.  Hence

`gamma(A)/mu>=1/2`

for this whole equicorrelation family, while (5) shows its infimum over dimension and `mu` is
exactly `1/2`.  This is a family theorem, not a proof of the global candidate.

## 3. The sharp surviving global candidate

The strongest constant compatible with (5) is

`K(A) >= (mu/2) A^{-1}`.                                  (6)

This is still open.  It is exactly the consequence that would follow from the T085 half-depth
certificate

`H_{ceil(n/2)}(A) >= (mu/2)A^{-1}`,

because `H_r(A)<=K(A)`.  Thus the half-depth constant `1/2` is not merely a convenient loss: the
signed-rank-one interior family makes it asymptotically optimal for every global one-step
`A`-energy matrix inequality.

## 4. Finite-time implication and the uniform-remainder warning

If (6), or more generally `K(A)>=c mu A^{-1}` for a universal `c>0`, were proved, the exact energy
identity gives

```
E[T_pi^T A T_pi]=A-AK(A)A <= (1-c mu)A.
```

Fresh independent permutations then imply

```
E||x_t||_A^2 <= (1-c mu)^t ||x_0||_A^2,
E||x_t||_A   <= (1-c mu)^(t/2)||x_0||_A.
```

Thus relative squared `A`-distance `epsilon` needs at most

`N <= n(c mu)^(-1) log(1/epsilon)` coordinate updates.  The candidate `c=1/2` gives the requested
`2n/mu` leading constant.

Boundary statement (2) alone does not supply this global conclusion.  Along a fixed isotropic ray
`A_mu=mu I+(1-mu)C`, the Schur perturbation formula gives

`gamma(A_mu)/mu -> lambda_min(S_C)`.

Consequently, (2) would give a pointwise small-`mu` neighborhood with any constant strictly below
`3/2`.  But the neighborhood can depend on `C` and `n`.  A dimension-uniform finite-time theorem
needs a remainder estimate uniform over all boundary strata and all approaches to them, plus an
interior estimate.  Compactness at each fixed dimension does not provide a dimension-independent
modulus, and multiple small eigenvalue scales require additional care.  Formula (3) also shows
that the interior can impose the smaller constant `1/2` even when all boundary directions enjoy
constant `3/2`.

## 5. Bare Jensen cannot prove even a smaller universal constant

One tempting shortcut is the valid lower certificate

```
K(A) >= (A+S)^{-1},
S=(A-I)^2/3+Diag(diag((A-I)^2))/6.
```

It would prove the sharp global target if `mu(A+S)<=2A`.  The signed-rank-one lift disproves this
route exactly.  For `A=mu I+(1-mu)11^T`, the parallel eigenvalues are

```
L=n-(n-1)mu,
S_parallel=(1-mu)^2(n-1)(2n-1)/6.
```

At `n=21,mu=9/20`, the Jensen-certified ratio is

```
L/[mu(L+S_parallel)]
=3200/6401
=1/2-1/12802 < 1/2.
```

There is an even smaller-dimensional transverse witness.  The transverse `S` eigenvalue is
`(1-mu)^2(n+1)/6`; at `n=12,mu=1/100`,

```
gamma_Jensen/mu=1/[mu+(1-mu)^2(n+1)/6]
                =20000/42671
                =1/2-2671/85342.
```

This is not merely a small constant miss.  For every fixed `mu in (0,1)`, sending `n` to infinity
makes this ratio asymptotic to `3/[n mu(1-mu)]`, hence zero.  Bare Jensen therefore cannot prove
`K(A)>=c mu A^{-1}` for **any** universal positive `c`.  A successful proof must retain the
variance discarded by Jensen or use the remaining-set/Bellman hierarchy.
